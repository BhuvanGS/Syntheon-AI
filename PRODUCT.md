# Product

## Register

product

## Users

Teams that ship — developers, project managers, and startup founders who run on meetings but hate manual ticket writing. They're in back-to-back Google Meet / Zoom / Teams calls and need the administrative work (transcription, ticket creation, sprint organization) to happen automatically. Their context: fast-moving, context-switching, tool-fatigued. The job: turn meeting conversations into structured, actionable project work without manual overhead.

## Product Purpose

Syntheon Hub is an AI-powered project management platform that joins meetings, transcribes them, extracts structured tickets, and organizes them into Kanban boards, sprints, and milestones automatically. It exists because the gap between "meeting ends" and "tickets are on the board" is where momentum dies. Success looks like: zero manual ticket writing, zero manual board updates, and a project state that's always current.

## Brand Personality

Bold, precise, technical. Dark, premium, confident. The interface should feel like a power tool — not a toy. Think Linear's craft, Raycast's density, a terminal's directness. Every pixel earns its place.

## Anti-references

- **Jira-style clutter**: no wall-of-panels, no 12-column dense tables, no button soup. Density without chaos.
- **Generic SaaS templates**: no purple-gradient hero, no stock-illustration cards, no "trusted by" logo strips.
- **Notion-style minimalism**: too flat, too white, too generic. This is a tool, not a blank page.

## Design Principles

1. **Show, don't tell** — the product demo is the marketing. Interactive showcases beat feature lists.
2. **Density with intent** — pack information tightly but hierarchically. Every pixel works; none decorates.
3. **Motion as feedback** — animations confirm actions and guide attention. Never decorative, never optional.
4. **Dark by default** — the brand lives in dark mode. Light mode is a concession, not the identity.
5. **One action per moment** — at any given time, the user should know exactly what to do next. No decision paralysis.

## Accessibility & Inclusion

- WCAG AA contrast targets (4.5:1 body text, 3:1 large text)
- `prefers-reduced-motion` support on all animations
- Keyboard-navigable interfaces with visible focus states
- Color-blind safe: never rely on color alone for status indication
