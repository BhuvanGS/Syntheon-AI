# Audio Directory

Place the cinematic score at `public/audio/score.mp3`.

The video is built to be scored afterward — no `<Audio>` tag is included
in the Remotion composition until a real score file exists here.

## Cue Points

See `CUE_POINTS` in `remotion/constants.ts` for frame-accurate markers
for every hard beat in the film. A sound designer can line up hits:

- Glass clicks on UI assembly (Act 3 beats)
- Digital pulse on the AI reveal (Ticket Extraction)
- Sub-bass hit on the logo (Ending collapse)
- Riser under the Act 2 → Act 3 transition (camera dive into light)
