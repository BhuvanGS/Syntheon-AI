# ORM Implementation Prompt — Syntheon-AI Backend (Drizzle ORM)

You are a senior backend engineer. Implement **Drizzle ORM** to replace the current direct Supabase client usage in `lib/db.ts`. The goal is to improve type safety, developer experience, and maintainability while preserving all existing functionality.

---

## Current State Analysis

The codebase currently uses direct Supabase client (`supabaseAdmin`) for all database operations in `lib/db.ts`. There are ~70 database functions with manual type definitions and row-to-model mapping.

### Tables (inferred from lib/db.ts):
1. **meetings** — meeting records with transcripts, specs, status
2. **specs** (legacy, now tickets) — feature specs from meetings
3. **tickets** — main ticket entity with dependencies, dates, assignees
4. **projects** — project containers with meetings, tickets, files, context
5. **ticket_dependencies** — dependency graph between tickets
6. **ticket_attachments** — file attachments for tickets
7. **ticket_comments** — comments on tickets
8. **ticket_activities** — activity log for tickets
9. **integrations** — GitHub/Linear integration tokens
10. **project_members** — project membership with roles

### Key Patterns to Preserve:
- Org-scoped queries (`getAllTicketsByOrg`, `getProjectsByOrg`, etc.)
- Project membership checks (`isProjectMember`, `getProjectMembers`)
- Dependency cycle detection and validation
- Cascade regression on ticket status changes
- Transaction-like operations (saveTickets with multiple inserts)

---

## Implementation Requirements

### 1. Why Drizzle ORM

**Drizzle ORM** is the best choice for this codebase:
- **SQL-first approach** — Full control over queries, no hidden magic
- **Supabase native** — Works seamlessly with Supabase PostgreSQL
- **Type-safe queries** — Auto-infer types from schema
- **Small bundle size** — Better performance than Prisma
- **Edge runtime compatible** — Works on Vercel Edge Functions
- **Drizzle Kit** — Excellent migration and introspection tools
- **No separate runtime** — Queries compile to SQL at build time

```typescript
// db/schema.ts
import { pgTable, uuid, text, integer, jsonb, timestamp, boolean, index, uniqueIndex } from 'drizzle-orm/pg-core';
import { relations } from 'drizzle-orm';

export const meetings = pgTable('meetings', {
  id: uuid('id').defaultRandom().primaryKey(),
  userId: text('user_id'),
  orgId: text('org_id'),
  projectId: text('project_id'),
  projectName: text('project_name').notNull(),
  meetingId: text('meeting_id').notNull().unique(),
  meetingUrl: text('meeting_url'),
  platform: text('platform').notNull(),
  transcript: text('transcript').default(''),
  specsDetected: integer('specs_detected').default(0),
  status: text('status').default('processing'), // completed | processing | failed | not_admitted
  botId: text('bot_id').unique(),
  branchName: text('branch_name'),
  deployUrl: text('deploy_url'),
  filePath: text('file_path').default(''),
  date: text('date').notNull(),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
}, (table) => ({
  meetingIdIdx: index('meeting_id_idx').on(table.meetingId),
}));

export const specs = pgTable('specs', {
  id: uuid('id').defaultRandom().primaryKey(),
  userId: text('user_id'),
  title: text('title').notNull(),
  type: text('type').notNull(), // feature | idea | constraint | improvement
  confidence: integer('confidence').notNull(),
  meetingId: text('meeting_id').notNull().references(() => meetings.id, { onDelete: 'cascade' }),
  timestamp: text('timestamp').notNull(),
  note: text('note'),
  projectId: text('project_id'),
  parentSpecId: text('parent_spec_id').references(() => specs.id, { onDelete: 'set null' }),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});

export const tickets = pgTable('tickets', {
  id: uuid('id').defaultRandom().primaryKey(),
  userId: text('user_id'),
  orgId: text('org_id'),
  meetingId: text('meeting_id').references(() => meetings.id, { onDelete: 'set null' }),
  projectId: text('project_id').references(() => projects.id, { onDelete: 'set null' }),
  parentId: text('parent_id').references(() => tickets.id, { onDelete: 'set null' }),
  title: text('title').notNull(),
  description: text('description').default(''),
  status: text('status').default('backlog'), // backlog | in_progress | done | blocked
  assignee: text('assignee'),
  assigneeUserId: text('assignee_user_id'),
  dependencyTicketId: text('dependency_ticket_id'),
  startDate: text('start_date'),
  dueDate: text('due_date'),
  deadlineTime: text('deadline_time'),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
}, (table) => ({
  meetingIdIdx: index('ticket_meeting_id_idx').on(table.meetingId),
  projectIdIdx: index('ticket_project_id_idx').on(table.projectId),
}));

export const projects = pgTable('projects', {
  id: uuid('id').defaultRandom().primaryKey(),
  userId: text('user_id'),
  orgId: text('org_id'),
  name: text('name').notNull(),
  repo: text('repo').notNull(),
  deployUrl: text('deploy_url'),
  branchBase: text('branch_base').default('main'),
  meetings: text('meetings').array().default([]),
  specIds: text('spec_ids').array().default([]), // ticket IDs
  files: text('files').array().default([]),
  context: text('context').default(''),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});

export const ticketDependencies = pgTable('ticket_dependencies', {
  id: uuid('id').defaultRandom().primaryKey(),
  projectId: text('project_id').notNull().references(() => projects.id, { onDelete: 'cascade' }),
  ticketId: text('ticket_id').notNull().references(() => tickets.id, { onDelete: 'cascade' }),
  dependsOnTicketId: text('depends_on_ticket_id').notNull().references(() => tickets.id, { onDelete: 'cascade' }),
  dependencyType: text('dependency_type').default('hard'), // hard | soft
  strength: text('strength').default('strong'), // strong | weak
  note: text('note'),
  ignoreCount: integer('ignore_count').default(0),
  escalated: boolean('escalated').default(false),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
}, (table) => ({
  ticketDependsOnUnique: uniqueIndex('ticket_depends_on_unique').on(table.ticketId, table.dependsOnTicketId),
}));

export const ticketAttachments = pgTable('ticket_attachments', {
  id: uuid('id').defaultRandom().primaryKey(),
  ticketId: text('ticket_id').notNull().references(() => tickets.id, { onDelete: 'cascade' }),
  projectId: text('project_id'),
  userId: text('user_id').notNull(),
  filename: text('filename').notNull(),
  fileUrl: text('file_url').notNull(),
  fileSize: integer('file_size').notNull(),
  fileType: text('file_type'),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});

export const ticketComments = pgTable('ticket_comments', {
  id: uuid('id').defaultRandom().primaryKey(),
  ticketId: text('ticket_id').notNull().references(() => tickets.id, { onDelete: 'cascade' }),
  projectId: text('project_id'),
  userId: text('user_id').notNull(),
  content: text('content').notNull(),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});

export const ticketActivities = pgTable('ticket_activities', {
  id: uuid('id').defaultRandom().primaryKey(),
  ticketId: text('ticket_id').notNull().references(() => tickets.id, { onDelete: 'cascade' }),
  userId: text('user_id').notNull(),
  actionType: text('action_type').notNull(),
  metadata: jsonb('metadata').$type<Record<string, unknown>>(),
  createdAt: timestamp('created_at').defaultNow(),
});

export const integrations = pgTable('integrations', {
  id: uuid('id').defaultRandom().primaryKey(),
  userId: text('user_id').unique().notNull(),
  githubToken: text('github_token'),
  githubOwner: text('github_owner'),
  githubAccessToken: text('github_access_token'),
  linearApiKey: text('linear_api_key'),
  linearTeamName: text('linear_team_name'),
  linearTeamId: text('linear_team_id'),
  updatedAt: timestamp('updated_at').defaultNow(),
});

export const projectMembers = pgTable('project_members', {
  id: uuid('id').defaultRandom().primaryKey(),
  projectId: text('project_id').notNull().references(() => projects.id, { onDelete: 'cascade' }),
  userId: text('user_id').notNull(),
  role: text('role').default('member'), // admin | member
  createdAt: timestamp('created_at').defaultNow(),
}, (table) => ({
  projectUserUnique: uniqueIndex('project_user_unique').on(table.projectId, table.userId),
}));

// Relations
export const meetingsRelations = relations(meetings, ({ many }) => ({
  tickets: many(tickets),
  specs: many(specs),
}));

export const specsRelations = relations(specs, ({ one, many }) => ({
  meeting: one(meetings, {
    fields: [specs.meetingId],
    references: [meetings.id],
  }),
  parent: one(specs, {
    fields: [specs.parentSpecId],
    references: [specs.id],
  }),
  children: many(specs),
}));

export const ticketsRelations = relations(tickets, ({ one, many }) => ({
  meeting: one(meetings, {
    fields: [tickets.meetingId],
    references: [meetings.id],
  }),
  project: one(projects, {
    fields: [tickets.projectId],
    references: [projects.id],
  }),
  parent: one(tickets, {
    fields: [tickets.parentId],
    references: [tickets.id],
  }),
  children: many(tickets),
  dependencies: many(ticketDependencies, { relationName: 'TicketDependent' }),
  blocking: many(ticketDependencies, { relationName: 'TicketBlocking' }),
  attachments: many(ticketAttachments),
  comments: many(ticketComments),
  activities: many(ticketActivities),
}));

export const projectsRelations = relations(projects, ({ many }) => ({
  tickets: many(tickets),
  members: many(projectMembers),
  dependencies: many(ticketDependencies),
}));

export const ticketDependenciesRelations = relations(ticketDependencies, ({ one }) => ({
  ticket: one(tickets, { relationName: 'TicketDependent', fields: [ticketDependencies.ticketId], references: [tickets.id] }),
  dependsOnTicket: one(tickets, { relationName: 'TicketBlocking', fields: [ticketDependencies.dependsOnTicketId], references: [tickets.id] }),
  project: one(projects, { fields: [ticketDependencies.projectId], references: [projects.id] }),
}));

export const ticketAttachmentsRelations = relations(ticketAttachments, ({ one }) => ({
  ticket: one(tickets, { fields: [ticketAttachments.ticketId], references: [tickets.id] }),
}));

export const ticketCommentsRelations = relations(ticketComments, ({ one }) => ({
  ticket: one(tickets, { fields: [ticketComments.ticketId], references: [tickets.id] }),
}));

export const ticketActivitiesRelations = relations(ticketActivities, ({ one }) => ({
  ticket: one(tickets, { fields: [ticketActivities.ticketId], references: [tickets.id] }),
}));

export const projectMembersRelations = relations(projectMembers, ({ one }) => ({
  project: one(projects, { fields: [projectMembers.projectId], references: [projects.id] }),
}));
```

### 3. Migration Strategy

1. **Install Drizzle ORM**:
   ```bash
   pnpm add drizzle-orm postgres
   pnpm add -D drizzle-kit
   ```

2. **Set DATABASE_URL**:
   - Extract from existing Supabase connection string
   - Format: `postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres`
   - Add to `.env.local` and `.env.example`

3. **Create Drizzle config** (`drizzle.config.ts`):
   ```typescript
   import type { Config } from 'drizzle-kit';
   import { env } from '@/lib/env';

   export default {
     schema: './db/schema.ts',
     out: './drizzle',
     dialect: 'postgresql',
     dbCredentials: {
       url: env.DATABASE_URL,
     },
   } satisfies Config;
   ```

4. **Generate migration** (creates SQL migration file):
   ```bash
   pnpm drizzle-kit generate
   ```

5. **Apply migration to Supabase**:
   ```bash
   pnpm drizzle-kit migrate
   ```

6. **Or use introspection** (if tables already exist):
   ```bash
   pnpm drizzle-kit introspect
   ```

### 4. Set Up Drizzle Database Connection

Create `db/index.ts` with Drizzle client:

```typescript
// db/index.ts
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import * as schema from './schema';

const connectionString = process.env.DATABASE_URL!;

const client = postgres(connectionString, {
  max: 1,
  idle_timeout: 20,
  connect_timeout: 10,
});

export const db = drizzle(client, { schema });

// For query logging in dev
if (process.env.NODE_ENV === 'development') {
  client.on('notice', (notice) => console.log(notice));
}
```

Then refactor `lib/db.ts` function by function:

**Example refactor**:

```typescript
// Before
export async function getTicketById(id: string): Promise<Ticket | null> {
  const { data, error } = await supabaseAdmin.from('tickets').select('*').eq('id', id).single();
  if (error) return null;
  return rowToTicket(data);
}

// After
import { db } from '@/db';
import { tickets, meetings, projects, ticketDependencies } from '@/db/schema';
import { eq } from 'drizzle-orm';

export async function getTicketById(id: string): Promise<Ticket | null> {
  const [ticket] = await db
    .select({
      id: tickets.id,
      userId: tickets.userId,
      orgId: tickets.orgId,
      meetingId: tickets.meetingId,
      projectId: tickets.projectId,
      parentId: tickets.parentId,
      title: tickets.title,
      description: tickets.description,
      status: tickets.status,
      assignee: tickets.assignee,
      assigneeUserId: tickets.assigneeUserId,
      dependencyTicketId: tickets.dependencyTicketId,
      startDate: tickets.startDate,
      dueDate: tickets.dueDate,
      deadlineTime: tickets.deadlineTime,
      createdAt: tickets.createdAt,
      updatedAt: tickets.updatedAt,
    })
    .from(tickets)
    .where(eq(tickets.id, id))
    .limit(1);

  if (!ticket) return null;
  return {
    id: ticket.id,
    user_id: ticket.userId ?? undefined,
    org_id: ticket.orgId ?? undefined,
    meeting_id: ticket.meetingId ?? undefined,
    projectId: ticket.projectId ?? undefined,
    parent_id: ticket.parentId ?? undefined,
    title: ticket.title,
    description: ticket.description,
    status: ticket.status as Ticket['status'],
    assignee: ticket.assignee,
    assignee_user_id: ticket.assigneeUserId,
    dependency_ticket_id: ticket.dependencyTicketId,
    start_date: ticket.startDate,
    due_date: ticket.dueDate,
    deadline_time: ticket.deadlineTime,
    createdAt: ticket.createdAt?.toISOString(),
    updatedAt: ticket.updatedAt?.toISOString(),
  };
}
```

**Key refactoring rules**:
- Keep function signatures identical (preserve API compatibility)
- Use Drizzle's query builder with `select()`, `where()`, and operators (`eq`, `and`, `or`, etc.)
- Use `.execute()` for writes (insert, update, delete) and `.limit(1)[0]` for single-row reads
- Convert Drizzle Date objects to ISO strings for consistency
- Preserve all business logic (dependency validation, cycle detection, etc.)
- Use Drizzle transactions (`db.transaction()`) for multi-step operations
- Use Drizzle relations API when needed, or explicit joins with `leftJoin`
